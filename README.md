# CyberSentry AI

An offline-first cybersecurity workbench for analyzing suspicious patterns in security logs.

## Features

* Rule-based detection of selected suspicious activity.
* Investigation and local case-history features.
* JSON export for investigation records.
* Browser-based interface designed for local use.

## Current Status

This is a prototype. Its current detection engine uses local rules. QVAC-powered offline AI inference has not yet been verified as integrated and functional.

## Running the Application

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Use the available interface to explore the prototype.

## Limitations

Detection results depend on the implemented rules and the input data. This prototype is not a replacement for professional security monitoring or incident-response systems.
